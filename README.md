# QaleenCraft 🧵✨

**A digital archive and discovery platform for Persian carpets.**  
Built with love by [Shamim](https://github.com/shimmim) — blending tradition, tech, and personalization.

---

## 🌟 Vision

To become the most accessible, intelligent, and beautifully curated platform for exploring and understanding Persian carpets — their design, stories, and origins.

---

## 🚀 Project Goals

- Build a full-stack web platform with modern tech (Spring Boot + React)
- Practice Agile & DevOps workflows (CI/CD, git-flow, documentation)
- Implement smart features (personalized suggestions, ML-based image search)
- Create a real-world portfolio-worthy project
- Potentially evolve into a real product or service

---

## 🛠️ Tech Stack

- **Frontend**: React / TailwindCSS *(planned)*
- **Backend**: Spring Boot, PostgreSQL
- **Infrastructure**: Docker, GitHub Actions, Vercel or Render (for hosting)
- **Extras**: Jira (Agile board), GitHub Projects, README-based docs

---

## 📦 Features (Planned)

- 🌍 Explore carpets by region, style, materials
- 🧠 Personalized suggestions based on user behavior (phase 2)
- 📸 Visual search with image input (phase 3)
- 🧾 Detailed info on each design: origin, story, materials
- 💾 Admin panel to upload/edit carpet entries
